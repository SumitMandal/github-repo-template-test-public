# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and do not harass anyone in any project space, online or offline.

## Reporting

Report unacceptable behaviour privately to a maintainer, such as [@SumitMandal](https://github.com/SumitMandal), using the contact details on their GitHub profile. Don't report it in a public issue. For abuse that happens on GitHub itself, you can also use GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature. All reports are reviewed promptly and kept confidential. Maintainers may remove comments, commits or contributors that break this code.
