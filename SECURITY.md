# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest minor release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please **do not open a public issue**.

Report it privately through **Security → Report a vulnerability** on this repository. Only the maintainers can see the report.

Include the affected version, steps to reproduce, and the impact you expect. We aim to acknowledge reports within 2 working days and to share a fix timeline within 7 days.
